# Jitendex 日中辞典（Yomitan 中文版）

这是一个基于 [Jitendex](https://github.com/Jitendex/Jitendex) 的非官方中文本地化版本，供 Yomitan 使用。

本项目以日文原词条、读音、词性和词条结构为主，英文释义仅作为辅助参考；英文释义和例句已经转换为中文。原始日文内容、图形资源及来源信息均予以保留。

> 这是社区派生版本，不是 Jitendex 官方发布物。Jitendex 官方项目仍然是日英词典。

## 其他语言版本

- [日印尼语版](https://github.com/greyindex/jitendex-yomitan-id)：常用前 20% 提供印尼语释义，其余长尾词条保留英文。

## 下载与安装

从 [Releases](https://github.com/greyindex/jitendex-yomitan-zh/releases/latest) 下载最新的 `jitendex-yomitan-zh-common20pct-gpt6-luna.zip`，然后在 Yomitan 的 **Dictionaries → Import** 中导入 ZIP 文件。

压缩包的 `index.json` 位于根目录，可以直接导入。该中文版本不包含指向官方英文版本的自动更新地址，因此不会误覆盖官方日英词典。

本版词典标题为「Jitendex.org [2026-08-11] 中文版 常用20%校订版」。已安装旧中文版的用户，导入后可停用旧版以避免重复显示；[初版](https://github.com/greyindex/jitendex-yomitan-zh/releases/tag/v2026.08.11-zh.1)仍可下载。

## 常用前 20% 校订结果

按固定 Jiten Global 2026-09-19 词频匹配，累计覆盖 **42,222 个常用词候选（约占词条 ID 的 20%）**。前 5% 保留 GPT-5.6 Luna 修正，新增 5%–20% 范围由 GPT-6 Luna 校对全部释义、例句和辅助说明。

### 初译与线上复校范围

中文释义和例句先以本地 **Qwen3.8-27B IQ2** 结果作为全库初译底稿；随后由 GPT-5.6 Luna 和 GPT-6 Luna 对按词频筛出的常用前 20% 做二次校订。这里的“20%”指 **42,222 个不同 JMdict 词条 ID，占 211,107 个有释义 ID 的约 20%**，不是说只有 20% 的词条有中文翻译。

其余约 **168,885 个 ID（约 80%）仍有 Qwen 初译**，但没有进入本轮系统性的线上模型语义复校。未入选部分包含长尾词条，也包含未匹配到词频数据的 ID；未匹配不能直接等同于低频。

### 怎样理解常用 20%

这 20% 是按 Jiten Global 词频表中的词形排名优先筛出的，因此预期对日常阅读和查词更有帮助，实际收益不应简单理解成“只能查到 20%”。不过，当前使用的频率文件只有词形和排名，没有词频次数或累计占比；所以现有数据**不能证明它覆盖了 99% 以上的实际阅读词次**。要给出可靠的词次覆盖率，需要另用有代表性的日语文本语料统计。

- 本次新增审读 **31,666 个 ID、120,476 个去重字段**。
- 本次修正 **3,573 个唯一字段**，展开至重复变体后为 **5,216 处修改**，涉及 2,691 个 ID。
- 累计修正 **5,171 个唯一字段、7,438 处实际变体内容**。
- 累计 **177 个字段待核实**（本次新增 172 个），保留原译并公开列出。
- 全部 435,448 条记录通过结构比较；ZIP 的 471 个文件通过 CRC 与逐文件哈希检查，日文、读音、图片、标签和署名保留。

## 仍然存在的问题

- **长尾及未入选词条没有经过本轮线上模型的系统性语义复校**；它们仍以 Qwen 初译为主，可能存在原模型的错义、术语误译、遗漏或不自然表达。
- 待核项涉及专业术语、义项对应、源文冲突及例句上下文。清单备注是模型的待核判断，不代表已经证实的上游错误；此前「体感」「ミス」「無条件」等 5 个字段的疑点仍保留。
- 常用 20% 是基于所选语料与词形匹配的候选范围，不是文本词次覆盖率或义项级绝对频率排名。1,309 个入选 ID 涉及同形同音歧义；另有 39,506 个 ID 未匹配词频，不能据此断言为低频。
- 本次是模型校对，**没有重新测得修正后的全库误译率，也不保证已校对字段零错误**。结构检查通过仅说明数据完整性，不代表语义准确率。
