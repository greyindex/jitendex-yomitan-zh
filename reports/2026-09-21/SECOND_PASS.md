# 第二次校对：常用 5% 校订版

发布版本：`v2026.08.11-zh.2`。上游数据仍为 Jitendex 2026-08-11；本轮更新中文译文，不是更新上游词典数据。

## 范围与方法

本轮以 Qwen3.8-27B IQ2 初版中文词典为基线，按 **Jiten Global 2026-09-19** 词频选取 10,556 个不同 JMdict ID，约占全部 211,107 个 ID 的 5%。通过表记和读音匹配，只进行 NFKC 与假名读音归一化，不借用纯跳转别名的频率。

对入选词的全部释义、例句、用法注释、交叉引用释义和辅助信息进行校对。精确去重只合并同一 ID 下原文与现译结构均相同的内容；不同译文仍分别审读，修改再展开到各个原始变体位置。

语义校对由 GPT-5.6 Luna 执行，同一时刻最多三路并行。主控负责分派、输入完整性检查、旧值核对、补丁合并和打包。本轮从分片准备到打包验证约 101 分钟。

初版曾随机抽查 2,000 个词条，其中 135 个被判为 major/critical（6.75%）。**这是修正前的抽样结果，不是本版的错误率，也不能直接用本轮修改数推算修正后的准确率。** 本轮不是新的随机抽样评测，尚未独立测得修正后全库误译率。

## 仍未解决的范围问题

1. **未入选部分没有经过本轮校对。** 长尾、未匹配词频的词条及其例句仍可能含有原译问题；本轮覆盖不能外推为全库已校正。
2. **“常用 5%”是候选范围。** Jiten 的语料分布影响排序。171,601 个 ID 匹配到词频，39,506 个未匹配；未匹配不等于低频。422 个入选 ID 涉及同形同音歧义，词形频率不能精确分配到各个义项。
3. **模型仍可能漏判或改错。** 专业术语、罕见义、语法说明、日英源文冲突和跨义项一致性仍值得后续人工或独立模型复核。通过输入与结构检查不等于通过独立语义正确率评测。

## 完整性与审计

- 343 个有效批次覆盖全部 11,531 组、86,698 个字段，补丁中每个旧值均与基线一致。
- 初期长分片出现过未实际审读的占位“通过”记录，已作废并重新审读；随后改为短批次接续。最终有效记录的完整输入均可在校对工具输出中对应，且读取先于提交。
- 全部 435,448 条记录逐条结构对比通过；其中 433,781 条完全未变。仅修改入选范围内的指定中文文字节点及新版 `index.json` 的标题、版本说明。
- 日文、读音、图形、标签、来源署名与许可保留；未入选词条没有被本轮补丁改写。
- 471 个 ZIP 文件的 CRC 与逐文件 SHA-256 均通过。此验证不包含对本版重新进行浏览器端 Yomitan 导入测试的声明。
