# 常用前 20% 校订报告

发布版本：`v2026.08.11-zh.3`（2026-09-23）。基于已发布的常用 5% 校订版 `v2026.08.11-zh.2` 扩展校对；上游仍为 Jitendex 2026-08-11。

## 范围与方法

沿用固定的 Jiten Global 2026-09-19 词频，在 211,107 个有释义的 JMdict ID 中选取前 42,222 个（约 20%）。通过表记和读音归一化匹配，不从纯重定向别名继承频率；同频时按词典优先级和 ID 稳定排序。

前 5% 的 10,556 个 ID 保留 GPT-5.6 Luna 校订成果。本次 GPT-6 Luna 最多三路并行，审读新增 31,666 个 ID 的全部释义、例句、注释、交叉引用说明及辅助字段。主控负责分派、完整输入可见性检查、旧值核对、结构验证和合并打包。

精确去重只合并同一 ID 下英文与现译结构均相同的组；不同现译分别审读，补丁再展开至各个原始变体。新增部分为 32,794 组、468 批、120,476 个字段，覆盖 48,007 条释义变体记录。从输入准备到安装包生成约 197.2 分钟。

## 校订结果

| 指标 | 本次新增 5%–20% | 累计前 20% |
| --- | ---: | ---: |
| 审读 JMdict ID | 31,666 | 42,222 |
| 历史审读去重字段 | 120,476 | 207,174 |
| 修正的唯一字段 | 3,573 | 5,171 |
| 展开至实际变体的修改处数 | 5,216 | 7,438 |
| 保留原译、待核实字段 | 172 | 177 |

本次修正涉及 2,691 个 ID、4,070 条记录、210 个 term bank。校对员自报严重度为 minor 1,318、major 2,020、critical 235；这些标签没有统一再评级，不能用来推算准确率。累计字段数按历次实际审读计数；前 5% 校订使少量译文组变得相同，因此历史数量可能与重新去重结果不同。

对主审读后尚未明确处理的 8 个旧抽检提示，GPT-6 Luna 另作专项复核：追加 2 项修正（已计入上述 3,573 项），确认保留 6 项，全部有明确结论。见 [hint_followup.csv](hint_followup.csv)。

## 待核事项与限制

- 累计 177 个字段保留原译，包括前 5% 遗留的 5 项。逐字段原文、现译和模型备注见 [uncertain.csv](uncertain.csv)。备注是尚未证实的待核判断，不代表已确认的上游错误或标准术语结论。
- 既有疑点包括「体感」的专业术语、「ミス」与英文 `myth` 的义项对应，以及「無条件」例句的日英肯否定冲突。新增待核项涉及专业术语、词头与义项对应、源文冲突和例句上下文等。
- **未入选词条与长尾没有经过本次语义校对**，仍可能含有原模型误译。模型校对也可能漏判或改错，尚未独立测得校订后的准确率。
- “常用 20%”是指定语料与词形匹配下的候选范围，并非文本词次覆盖率或义项级的绝对频率排名。前 20% 有 1,309 个 ID 涉及同形同音归属歧义；全库另有 39,506 个 ID 未匹配到词频，未匹配不等于低频。
- 初版随机抽查的 6.75% major/critical 是修正前结果，不能当成本版错误率，也不能从本次修改数推算修正后误译率。

## 数据完整性

所有 435,448 条记录已相对前 5% 版逐条比较，431,378 条完全未变。只修改计划中的中文内容节点及新版 index 的标题和版本说明；日文、读音、标签、链接、图片、许可和署名保留。原始英文及前 5% 基线哈希未变，471 个 ZIP 文件通过 CRC 和逐文件 SHA-256 校验。

所有新增审读组的完整 EN/ZH/JA 输入在提交前均可对应到 Luna 工具输出。此项证明输入可见性，不构成独立语义复核；本次完整性检查也不包含重新进行浏览器端 Yomitan 导入测试的声明。
